## 3. Debug: "Method Not Allowed" is not valid JSON

**Reproduce:** `curl -X POST https://automail.myaiaplan.com/api/auth/login` → `405`, `Allow: GET, HEAD`, body text — เกิดทุกครั้ง

**Breadcrumbs**

| Run | ผล | สรุป |
| :--- | :--- | :--- |
| `POST /api/auth/login` ผ่านโดเมน | 405 text | ไม่ใช่ Express (Express ไม่มี 405) |
| `GET /api/status`, `/api/xyz` ผ่านโดเมน | 403 `Forbidden` text | Express ตอบ JSON เสมอ → proxy บล็อก |
| `GET /does-not-exist` | 200 index.html | SPA fallback ที่ proxy |
| Response headers | `Alt-Svc: h3`, CSP/HSTS, ไม่มี `Server` | Caddy ใส่ header เอง |
| `GET http://IP:5000/api/status` | 200 JSON `live` | Express ปกติ |
| `POST http://IP:5000/api/auth/login` | 403 JSON "ยังไม่ได้รับอนุญาต" | login logic ปกติ |

**ต้นเหตุ:** `/etc/caddy/sites/automail.caddy` เป็น **"PUBLIC PREVIEW (static only)"** โดยตั้งใจ — เสิร์ฟ `/srv/automail-preview` ด้วย `file_server`, `respond 405` ทุก method ที่ไม่ใช่ GET/HEAD และ `respond 403` ทุก path `^/(api|rest|webhook|...)` ไม่มี `reverse_proxy`

**สมมติฐานที่ตัดทิ้ง:** Express ตอบ 405 เอง (ไม่มีในโค้ด), `.env` ขาดค่า (status เป็น live แล้ว), proxy ชี้ upstream ผิด (จะได้ 502 ไม่ใช่ 405)
